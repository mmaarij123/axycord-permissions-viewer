# Source provenance

The Permissions Viewer implementation is maintained by Maarij and ported from
https://github.com/mmaarij123/microcord-permissions-viewer.

The Axycord SDK configuration and plugin discovery contract follow
https://github.com/Axycord/Axycord-Plugin-Template at commit
`2a36ff842ede7b4da312b41005782f3146588ca9`. Its settings script,
Gradle properties, signing-properties example, and wrapper files are retained.

The template itself was adapted from https://github.com/microcord/plugin-template
at commit `13af5561efa57aefc773ba8bee429bd901328028`. That inherited snapshot
contains no standalone LICENSE. The MIT license covers the Permissions Viewer
implementation. Inherited template files retain their upstream license status.
The Gradle Wrapper retains its Apache-2.0 copyright and license notices.

The separately distributed Axycord host and SDK retain AGPL-3.0-only. Their source
and license are available at https://github.com/Axycord/Axycord.
